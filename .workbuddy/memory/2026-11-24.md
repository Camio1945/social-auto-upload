## Windows 开机自启（backend + frontend）

- 需求：Flask 后端（sau_backend.py，:5409）与 Vite 前端（sau_frontend，:5173）随系统启动。
- 方案：pythonw.exe 静默启动器 + 用户登录启动文件夹快捷键（无需管理员权限）。
  放弃 .vbs/wscript 方案——安全工具会拦截 LOLBin。
- 新增 `scripts/`：
  - `launcher.pyw`：start/stop/status，纯标准库；按端口幂等启动（已占用则跳过），
    日志写 logs 下并按 5MB 轮转；用 node 直接跑 vite/bin/vite.js（不依赖 npm/PATH）；
    设 BROWSER=none 避免开机弹浏览器。
  - `install-autostart.ps1` / `.bat`：探测 python/node 绝对路径写入 `scripts/paths.json`（已加 .gitignore），
    在 Startup 目录创建 `Social Auto Upload.lnk` → pythonw.exe launcher.pyw。
  - `uninstall-autostart.ps1` / `.bat`、`README.md`。
- 已实际执行安装（shortcut 已生成，paths.json 已写），两个服务当前已在运行。
- 踩坑：PowerShell 7 `Set-Content -Encoding utf8` 会带 BOM，导致 json.loads 失败 →
  改用 `[System.IO.File]::WriteAllText(..., UTF8Encoding($false))`，读取侧用 utf-8-sig 兜底。
